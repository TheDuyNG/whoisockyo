## Project

Project name: `whoisockyo`

`whoisockyo` is a full-stack personal developer portfolio with a private dashboard for managing portfolio content.

The project should feel modern, minimal, technical, premium, and production-ready.

All code, comments, file names, variable names, documentation, API responses, and database fields must be written in English.
